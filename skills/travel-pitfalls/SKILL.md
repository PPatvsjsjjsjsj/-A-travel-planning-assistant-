# 避坑建议

- 交通票务优先官方渠道，警惕所谓内部票、代抢保证和非正规接送。
- 住宿核对实际地址、交通距离、取消政策、押金和窗型，不只看宣传地名。
- 景区核验预约入口、开放区域和末班交通；不购买无明确内容的套票。
- 对免费体验、低价团、祈福消费、玉石药材和强制拍照保持谨慎。
- 餐饮先看菜单和计价单位，海鲜、水果、茶叶等确认按份、按斤还是按克。
- 发生纠纷时保留订单、支付记录和现场证据，通过平台、12345 或 12315 合理处理。
